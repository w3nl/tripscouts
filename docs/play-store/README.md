# Google Play: store listing

The order of all steps (key, Play Console, upload) is in [../publish-android.md](../publish-android.md).

Everything Play Console asks for in **Grow users → Store presence → Main store listing**, and in **Policy → App content**. Make the images again with `npm run store` (for example after a big change to the game).

Set the **default language to English (United Kingdom) – en-GB** and add **Dutch (nl-NL)** as a translation (Store presence → Main store listing → Manage translations).

**The new name:** the game was called Cabin Week; it is now **TripScouts**. In Play Console only the texts below change (app name, descriptions, website, privacy policy). The package name `nl.w3nl.cabinweek` stays: it can never change, and players never see it.

```text

Walk, jump, slide and swim your way through every day. Find the three lost things, help the others with a task and crack the code lock with the clues on the signs along the way.

Every trip plays differently:

• The Veneto in summer: hop by vaporetto from island to island in Venice, Murano and Burano, flamingos in the lagoon, opera in Verona's Arena, the Dolomites and the Lido

• Play as one of the nine, or make your own hero: height, hair, coat, glasses, hat and scarf
• Locks of every kind: codes, tunes, colours, arrows, words and clocks, with hints if you get stuck
• Pull levers, light lamps, race the bell and walk lost animals home

• One app for your phone, tablet and Google TV

No ads, no purchases and no data leaves the device.
```

### Content rating, question by question

Policy → App content → **Content rating** asks the IARC questionnaire; Play works out the ratings from the answers (you don't pick an age). The wording in Play Console can differ a little.

| Question | Answer | Why |
|---|---|---|
| Category | **Game** | |
| Violence | **Yes: cartoon or fantasy violence, in a comical, child-like setting.** No blood, not realistic, not against humans | You jump on cartoon animals; they fall over with a "whee" and a "Pfff!" and disappear. Animals walk towards you when you are close |
| Fear, horror | No | The dark cave, the troll forest and the trolls are cosy, not scary |
| Sexuality, nudity | No | |
| Bad language | No | |
| Drugs, tobacco | No | |
| Alcohol | **Only references** (if Play asks): no use shown, not encouraged, never by children | Mulled wine is mentioned at the Christmas markets ("mulled wine for the grown-ups, hot chocolate for the kids"), there are wine barrels and vines on the grape harvest day, and "the grown-ups taste the wine". Answer honestly; Play may add a small note such as "Alcohol Reference" next to the rating |
| Gambling or simulated gambling | No | |
| Crude humour | No | Jokes about the wifi, chips and Uno |
| Users can talk to or interact with each other | No | No chat, no online play |
| Shares the user's location | No | |
| Digital purchases | No | |
| Unrestricted internet or a web browser | No | The game runs offline in its own WebView |

PEGI 3 allows very mild violence in a comical or child-like setting. **Got PEGI 7 instead?** Then check the violence answer first (cartoon, comical and child-like, not realistic), then the alcohol answer (references only, no use shown). If it stays higher, removing the few wine references from the texts would lower it.

**Target audience and the Families policy:** with age groups under 13, Google Play's Families policy applies. TripScouts meets it: no ads, no data collected or shared (Data safety), and a privacy policy (`https://tripscouts.online/privacy.html`, also linked from the title screen inside the app).
